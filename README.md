# AI Recruitment Automation System

An AI-powered system designed to automate and support the recruitment process, from candidate application and CV analysis to technical evaluation and interview management.

The system combines Large Language Models (LLMs), Natural Language Processing (NLP), AI agents, and workflow automation to assist recruiters in evaluating candidates more efficiently and consistently.

---

## Overview

The recruitment process often requires recruiters to manually review CVs, analyze candidate profiles, evaluate technical skills, and manage interviews.

This project aims to automate and simplify these tasks through an intelligent recruitment system.

The solution provides a centralized environment where recruiters can manage job offers and candidates while AI-powered components analyze candidate information and support the evaluation process.

---

## Main Features

- Job offer management
- Candidate application management
- CV processing and analysis
- Automatic information extraction from CVs
- Candidate profile generation
- AI-powered candidate evaluation
- Technical assessment
- Recruitment decision support
- Interview scheduling
- Interview management
- Recruiter dashboard
- Automated recruitment workflows

---

## AI & Multi-Agent Architecture

The system is based on a multi-agent architecture.

Each intelligent component is responsible for a specific task within the recruitment workflow. The agents communicate with backend services and data sources to process information and generate evaluation results.

The architecture combines:

- Large Language Models (LLMs)
- Natural Language Processing (NLP)
- AI agents
- REST APIs
- Workflow automation
- PostgreSQL

---

## Recruitment Workflow

The main recruitment workflow is organized as follows:

Candidate Application  
↓  
CV Upload  
↓  
CV Analysis & Information Extraction  
↓  
Candidate Profile Generation  
↓  
Candidate Evaluation  
↓  
Technical Assessment  
↓  
Evaluation Results  
↓  
Interview Scheduling  
↓  
Recruitment Decision
